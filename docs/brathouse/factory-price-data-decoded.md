## Add-ons (RMB, from the factory)
- **Brown:** +20 over black.
- **Highlight:** +40 over black (+50 on 18" body wave and curly).
- **Ombré:** same price as highlight.
- **HD lace:** 5×5 HD +130; 13×4 HD +180; 13×6 HD +200. To confirm: is each amount added to the glueless 13×4 base price?
- **14A:** about 1.55–1.7× the 12A price.
  - 18" straight 650; 20" straight 760.
  - 20" body wave 835; 22" body wave 980.
  - 20" curly 875; 18" afro kinky 780.
  - Brown and highlight are +20 and +40, the same as 12A.
- **To check:** the 14A sheet lists the 8" bob at 210, the same as 12A.

## Landed cost (from the case study)
- Landed cost is about factory price + shipping: roughly ¥23 per bob and ¥37 per long wig (RMX, ¥345 per 3.7 kg parcel).
- Exchange rate: ¥1 = R2.47.
- The current sell prices give 33–43% margin. Import duty and VAT are excluded.

## Pricing rules (decided 11 Nov 2026)
- **Target gross margin on every wig: 38%** (price = landed cost ÷ 0.62).
  - Never below **33%**.
  - Entry bobs can go up to about 43%.
- **Add-ons and upgrades** (HD lace, colors, density, finishing): **40% margin**, i.e. cost ÷ 0.60.
- **Exchange rate used for pricing: ¥1 = R2.55.** This is a buffer over the case-study rate of R2.47.
- **Rounding:** round up to the nearest R…99.
- **Assumption:** website sales pay no agent commission. If agents earn on web sales, raise the target.
- **Missing data:** any combination without factory data shows "quote on WhatsApp" and is never guessed.
